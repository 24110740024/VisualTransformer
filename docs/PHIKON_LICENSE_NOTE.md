# Phikon-v2 attribution and usage

The v5 comparison uses [Owkin Phikon-v2](https://huggingface.co/owkin/phikon-v2), revision `2ae989a9c40cffaa27f0a6cb29cc94d1d6f9a5fd`. The backbone is frozen. Per-image CLS features are L2-normalized and used by logistic-regression classifiers fitted separately within each training role.

The model weights and feature caches are not distributed in this repository.
