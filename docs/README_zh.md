# 小鼠肺组织 H&E 图像分析

本仓库提供热与臭氧复合暴露研究中，小鼠肺组织 H&E 图像分类、动物级病理评分及关联分析的代码和结果。

## 方法概述

当前实现（v6）采用 ImageNet 预训练 ViT-B/16，并在训练集中进行类别与来源平衡采样。动物级评分通过来源隔离的三折交叉拟合获得：每只动物及其同源图像均排除在对应模型的训练集和验证集之外，计算固定窗口的平均病变概率，再对三个随机种子的评分等权平均。

分类数据包含 23,309 张训练图像、7,909 张验证图像及 8,704 张测试图像，分别来自 19、5 和 4 个来源切片。关联分析包含 21 只动物、7 个实验组及 132,032 个固定窗口位置。

## 代码与数据

| 目录 | 内容 |
|---|---|
| `rebuild_v6/` | 模型训练、分类评估、整片窗口推理、动物评分与统计分析 |
| `data/` | 固定数据划分、图像身份和窗口坐标，不包含原始切片 |
| `results/` | 模型对照、预测值、统计表、图件和训练记录 |

## 结果复核

使用 Python 3.11 或更高版本，可在 CPU 上直接复核仓库内预测值对应的统计结果：

```bash
python -m pip install -r requirements-analysis.txt
python scripts/verify_results.py
python scripts/verify_results.py --full-bootstrap
```

模型重新训练和图像推理还需要原始图像、初始化权重及 CUDA 环境。详细操作见[复现说明](REPRODUCING.md)，数据字段见[数据说明](../data/README.md)。

## 结果与适用范围

v6 的分类 AUC 为 0.891999，来源簇自助法 95% 置信区间为 [0.848038, 0.946250]。动物评分与 Area、IL6 的 Pearson 相关系数分别为 0.699976 和 0.720957。全部配置的结果见[结果目录](../results/README.md)。

各模型配置在相同测试来源上进行了比较，v6 的展示选择发生于结果评估之后，因此这些比较属于探索性分析。测试集仅含 4 个来源，关联分析仅含 21 只动物；图像块、随机种子和重复标注不能作为独立生物学样本。v6 的组内去均值相关系数为 0.054569 和 0.173181，不支持较强的组内关联解释。

热图表示窗口分类概率，并非像素分割或经校准的病变面积。方法、参考标注范围和其他限制见[方法说明](METHODS_AND_LIMITATIONS.md)。代码许可及 Phikon 比较结果的许可范围见[第三方声明](../THIRD_PARTY_NOTICES.md)。
