# 小鼠肺组织 H&E 数字病理图像分析

本仓库提供热与臭氧复合暴露研究中，小鼠肺组织 H&E 全切片图像（WSI）病变分类、动物级病理评分与关联分析的完整代码及数值结果。

## 方法概述

主线模型（`v6`）基于 ImageNet 预训练 ViT-B/16，在统一物理视野尺度下结合类别与来源平衡采样进行微调。动物级病理评分通过来源隔离（source-aware）的三折交叉拟合获得：每只测试动物及其同源切片均严格排除在对应训练集和验证集之外，对固定整片窗口的预测病变概率求均值，并对三个随机种子结果等权平均。

- **图像块分类（`a6`）**：包含 23,309 张训练图像、7,909 张验证图像和 8,704 张测试图像，分别来自 19、5 和 4 张独立来源切片。
- **动物级关联分析（`a5`）**：涵盖 7 个实验组共 21 只小鼠，基于 132,032 个固定整片窗口位置。

## 标注与切块流程

原始切片及 QuPath 标注由研究合作者提供，导出脚本（[qupath_tiler_v2.groovy](../preprocessing/qupath/qupath_tiler_v2.groovy)）据此生成 224 × 224 PNG 图像块：Lesion 取自纳入 ROI 内的中心区域，Normal 由 ROI 外采样的正常子类别合并而成；无有效标注的切片自动跳过。经确定性去重与来源隔离划分后形成最终数据集，详细规则见[切块方法](PATCH_GENERATION.md)。

## 仓库目录

| 目录 | 说明 |
|---|---|
| `preprocessing/qupath/` | QuPath 切块脚本与导出溯源记录 |
| `rebuild_v6/` | 模型训练、分类评估、整片窗口推理、动物评分与统计分析 |
| `data/` | 固定划分清单、样本身份映射与窗口坐标（不含原始切片） |
| `results/` | 预测值、统计表、论文图件（PNG/SVG）与训练记录 |
| `scripts/` | 数据准备与一键结果复核脚本 |
| `tests/` | 数据隔离、采样逻辑与数值一致性单元测试 |
| `environment/` | 已记录的软硬件环境 |

## 快速复核统计结果

使用 Python 3.11 及以上版本，可在纯 CPU 环境下直接基于仓库内的预测表复核全部指标与置信区间：

```bash
python -m pip install -r requirements-analysis.txt
python scripts/verify_results.py
python scripts/verify_results.py --full-bootstrap
```

完整重新训练与整片推理需另备原始切片、预训练权重及 CUDA 环境，详细步骤见[复现说明](REPRODUCING.md)。

## 主要结果与适用说明

- **分类性能**：主线模型 `v6` 的测试集 AUC 为 **0.892**（来源簇自助法 95% CI：`[0.848, 0.946]`），优于随机初始化 ViT（0.870）、ResNet-50 基线（0.856）等对照配置。
- **动物级关联**：在 21 只动物队列中，`v6` 评分与病变面积（Area）及炎症指标（IL-6）的 Pearson 相关系数分别为 **0.700**（Holm 校正 `p = 0.0012`）和 **0.721**（Holm 校正 `p = 0.0009`）。完整精度数值见[结果目录](../results/README.md)。
- **研究范围**：当前评估基于 4 张留出测试切片与 21 只动物，动物级关联主要反映不同暴露组之间的整体差异；空间热图表示窗口级病变概率而非像素级分割。详细统计诊断与局限性说明见[方法与局限](METHODS_AND_LIMITATIONS.md)，代码及第三方模型许可范围见[第三方声明](../THIRD_PARTY_NOTICES.md)。
