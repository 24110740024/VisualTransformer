These files preserve the original v6 code and supporting numerical/audit/visualization code. They are provided for provenance and code review. The original scripts reference a larger frozen local dependency graph, completed-stage markers, private data paths and selected model weights. This directory alone is not a standalone executable reproduction bundle.

Use `rebuild_v6/` and `docs/REPRODUCING.md` for the portable entrypoints. Full archived dependencies and original weights remain in the authors' sealed handoff. Do not edit archived files to bypass their checks. The byte hashes are recorded in `20260926/SOURCE_SHA256.json` and the release inventory.
